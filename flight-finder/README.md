# טיסות זולות – תוסף Chrome

קורא חיפוש טיסה מאתר חברת תעופה (למשל אל על) ופותח את אותו חיפוש בגוגל פלייטס, סקייסקנר, קאיאק ומומונדו.

## התקנה
1. `chrome://extensions` → הפעלת "מצב מפתח".
2. "טען פריט לא ארוז" → בחירת תיקיית `flight-finder`.
3. בעמוד תוצאות חיפוש באתר חברת תעופה, לחצו על האייקון ואז "חפש באתרים אחרים".

הערה: זיהוי המוצא/יעד/תאריכים הוא ניסיון טוב מהעמוד; אפשר לתקן ידנית בפופאפ. קודי יעד הם קודי שדה תעופה או עיר (LON, PAR, NYC...).

## בדיקות
`node tests/run.js` מריץ 600+ בדיקות על קורא המחירים (pagelib.js) מול עמודים שנוצרים מתבניות של Trip.com, Kayak, Skyscanner ואחרים, כולל "מלכודות" (התראות מחיר, מסננים, מלון/רכב). `node tests/perf.js` בודק ביצועים. דורש playwright.
